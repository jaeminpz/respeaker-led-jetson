ReSpeaker 2-Mics Pi HAT v2.0 — LED 검수 USB
===========================================

이 폴더를 USB 에 통째로 복사해서 테스트기기에 꽂으면 된다.


쓰는 법
-------

  1. USB 를 테스트기기에 꽂는다
  2. 파일 관리자에서 USB 를 연다
  3. "LED테스트.bat" 를 오른쪽 클릭 -> "프로그램으로 실행"
     (Run as a Program / Execute)
  4. 터미널 창이 열리고 암호를 묻는다 -> 기기 사용자 암호
  5. 검사가 돌고, 마지막에 "LED 가 제대로 보였나?" 를 묻는다 -> y 또는 n
  6. 결과: 통과 / 실패

터미널을 쓰는 게 편하면:

  bash /media/<사용자>/<USB이름>/LED테스트.bat


왜 확장자가 .bat 인가
---------------------

도스 배치파일이 아니다. 내용은 그냥 bash 스크립트다.

USB 가 FAT32/exFAT 이면 리눅스가 showexec 옵션으로 마운트하는데, 이때 실행
권한을 받는 확장자는 .bat / .exe / .com 뿐이다. .sh 는 chmod +x 를 해도
조용히 무시되어 "허가 거부" 가 난다. .exe 로 하면 도스 실행파일로 인식되어
파일 관리자가 실행을 거부한다. 그래서 .bat 이다.

USB 를 ext4 로 포맷했다면 이런 제약이 없고 실행.sh 를 써도 된다.


더블클릭으로 안 되는 이유
-------------------------

요즘 GNOME 파일 관리자(Nautilus)는 텍스트 스크립트를 더블클릭해도 실행하지
않고 편집기로 연다. 예전에 있던 설정(executable-text-activation)도 없어졌다.
그래서 오른쪽 클릭 -> "프로그램으로 실행" 이 확실한 방법이다.

매번 누르는 게 번거로우면, 기기 바탕화면에 바로가기를 만들어두는 편이 낫다.
필요하면 만들어 줄 수 있다.


들어 있는 것
------------

  LED테스트.bat     런처. 이걸 누른다.
  실행.sh           터미널용 진입점 (같은 것을 부른다)
  files/
    led_test.py        검수 본체. 이 파일 하나만으로도 동작한다.
    led_controller.py  음성 어시스턴트용 상태 표시 (9개 상태)
    respeaker_led.py   APA102 드라이버 본체


런처가 하는 일
--------------

  1. 파일 관리자에서 눌렀으면 터미널 창을 열어 그 안에서 다시 실행한다
     (진행 상황과 실패 사유를 봐야 하므로)
  2. sudo 로 root 권한을 얻는다 (/dev/mem 으로 padctl 수정)
  3. USB 는 실행 권한이 제한되므로 검사 파일을 /tmp 로 복사해 돌린다
  4. 끝나면 결과를 남기고 Enter 를 기다린다 (창이 바로 닫히지 않게)


전제
----

  * Jetson Orin Nano (L4T R36.x / JetPack 6.x) + ReSpeaker 2-Mics Pi HAT v2.0
  * python3-gpiod  — 없으면: sudo apt install python3-libgpiod
    (없을 때 검사 스크립트가 이 명령을 알려준다)


알아둘 것
---------

  * LED 는 한 번에 한 프로세스만 잡을 수 있다. 다른 LED 프로그램이 떠 있으면
    실패한다.
  * APA102 는 리셋 핀이 없다. 이상한 색으로 굳으면 전원을 완전히 내려야 한다.
  * 설정은 레지스터에만 있어 재부팅하면 사라진다. 실행할 때마다 다시 적용하므로
    부팅 설정을 건드릴 필요는 없다.
